# Demo captures

Generated by `node demo.mjs`, which drives a real Chromium against a running
portal with Playwright. It is not a mock-up: the portal launches a game-server
process, the browser joins it over WebSocket, and these are screenshots of that
session.

The frame rates in the HUD are from software rendering (SwiftShader) inside a
container with no GPU. On real hardware the same scene runs far faster; the
numbers worth reading are the chunk and triangle counts, and that the mesher
backend says `wasm`.
